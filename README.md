# 양곡 온라인 시험실

학교용 온라인 시험·수행평가 플랫폼입니다. 핵심 구조는 `시험지 → 시험방 → 응시기록`으로 분리되어 있어 같은 시험지를 여러 반에 반복 사용할 수 있습니다.

## 현재 구현 기능

- 교사 이름 + 내선번호 4자리 로그인/최초 등록
- 교사별 시험방 / 시험지 / 학생명단 관리
- 반 학생명단 XLSX/XLS/CSV 업로드
- 반 명단 기준 응시 중 / 제출 / 미응시 / 연결 끊김 자동 대조
- PDF / XLSX / XLS / HWPX 문제지 업로드 및 문항 번호 기반 자동 분할
- 웹에서 직접 문항 작성·수정
- 문항 유형: 서·논술형 / 단답형 / 장문형 / 객관식 5지선다 / OX
- 시험지 복사
- 동일 시험지의 다른 반 실시
- 6자리 시험방 접속 코드
- 학생 인증: 학번+생년월일 / 학번+이름 / 학번+별명
- 전체화면 시험, 타이머, 자동 저장, 제한시간 종료 시 자동 제출
- 전체화면 해제 / 창 이탈 / 탭 이탈 / 복사·붙여넣기·잘라내기 / 우클릭 / 개발자도구 단축키 / 오프라인·온라인 / 재접속 기록
- 교사용 감독 화면
- 전체 답안 XLSX 다운로드
- 학생 개인별 답안 PDF 다운로드
- 제출자 전체 개인 PDF ZIP 다운로드
- Netlify Blobs 기반 서버 저장으로 배포 후에도 데이터 유지

## 중요한 제한

일반 웹브라우저는 운영체제의 `Alt+Tab` 자체를 막을 수 없습니다. 현재 앱은 다른 창·탭으로 이동한 사실을 감지하여 기록하고, 전체화면 필수 시험에서는 전체화면이 풀리면 답안 입력 화면을 잠급니다. OS 수준 차단이 필요하면 추후 Safe Exam Browser 또는 Windows 키오스크 모드를 결합해야 합니다.

## 저장 구조

Netlify Blobs를 사용합니다.

- 교사: 내선번호 원문을 저장하지 않고 SHA-256 해시로 보관
- 학생명단: 생년월일 원문을 저장하지 않고 SHA-256 해시로 보관
- 시험지, 시험방, 응시기록, 답안, 부정행위 로그: 전역 데이터 저장소
- 원본 문제 파일: 별도 Blob 저장소

비운영 배포에서는 deploy-scoped store를 사용하고, production 배포에서는 global store를 사용합니다.

## 로컬 실행

Node.js 20 이상 권장.

```bash
npm install
npm run dev
```

Netlify CLI 개발 서버가 실행되며 정적 화면과 `/api/*` 서버 함수를 함께 테스트할 수 있습니다.

## Netlify 배포

1. Netlify에서 `ryujee79/yg_no_ai` GitHub 저장소를 새 프로젝트로 연결합니다.
2. Build command는 비워 두거나 `npm run build`를 사용합니다.
3. Publish directory는 `.` 입니다.
4. Functions directory는 `netlify/functions`이며 `netlify.toml`에 이미 설정되어 있습니다.
5. Production 배포 후 앱 데이터는 Netlify Blobs의 global scope에 유지됩니다.

별도의 DB 계정이나 AI API 키는 필요하지 않습니다.

## 원본 파일 크기

시험지 분석은 브라우저에서 수행합니다. 원본 파일 서버 보관은 현재 요청 크기를 고려해 6MB 이하 파일을 대상으로 합니다. 6MB를 넘더라도 브라우저에서 문항을 추출해 시험지를 저장하는 기능은 사용할 수 있습니다.

## 운영 권장 사항

- 교사 최초 직접 등록 기능은 초기 테스트를 위한 기능입니다. 실제 운영 전에는 관리자 교사명단 기반 등록으로 변경하는 것을 권장합니다.
- 학생 개인정보가 포함되므로 Netlify 프로젝트 접근권한과 GitHub 저장소 권한을 학교 운영 정책에 맞게 관리해야 합니다.
- 실제 시험 전에는 학교 PC 브라우저와 네트워크 환경에서 여러 학생이 동시에 접속하는 부하 테스트를 진행하는 것이 좋습니다.
