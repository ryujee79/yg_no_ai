# 양곡 온라인 시험실

`GitHub 저장소 + GitHub Pages + GitHub Actions`만 사용하는 버전입니다.

## 현재 구현 기능

- 교사 이름 + 내선번호 4자리 로그인/최초 등록
- 교사별 시험방 / 시험지 / 학생명단 관리
- 반 학생명단 XLSX/XLS/CSV 업로드
- 반 명단 기준 응시 중 / 제출 / 미응시 / 연결 끊김 대조
- PDF / XLSX / XLS / HWPX 문제지 업로드 및 문항 번호 기반 자동 분할
- 웹에서 직접 문항 작성·수정
- 문항 유형: 서·논술형 / 단답형 / 장문형 / 객관식 5지선다 / OX
- 시험지 복사
- 동일 시험지의 다른 반 실시
- 6자리 시험방 접속 코드
- 학생 인증: 학번+생년월일 / 학번+이름 / 학번+별명
- 전체화면 시험, 타이머, 자동 저장, 제한시간 종료 시 자동 제출
- 전체화면 해제 / 창 이탈 / 탭 이탈 / 복사·붙여넣기·잘라내기 / 우클릭 / 개발자도구 단축키 / 오프라인·온라인 / 재접속 기록
- 교사용 감독 화면
- 전체 답안 XLSX 다운로드
- 학생 개인별 답안 PDF 다운로드
- 제출자 전체 개인 PDF ZIP 다운로드

## GitHub Pages 단독 운영의 중요한 제한

GitHub Pages는 정적 웹 호스팅입니다. 서버 프로그램, 공용 데이터베이스, WebSocket 서버를 실행하지 않습니다.

따라서 이 저장소의 GitHub Pages 버전은 데이터를 각 브라우저의 `IndexedDB`에 저장합니다.

- 같은 브라우저에서는 교사 화면과 학생 화면을 여러 탭으로 열어 시험 흐름을 테스트할 수 있습니다.
- 브라우저를 종료해도 일반적으로 데이터는 남습니다.
- 하지만 다른 PC, 다른 휴대폰, 다른 브라우저에는 데이터가 자동으로 전달되지 않습니다.
- 따라서 여러 학생이 각자 다른 기기에서 접속하여 답안을 한곳에 모으는 실제 학교 운영은 GitHub Pages만으로는 구현할 수 없습니다.
- 이 제한을 감추기 위해 GitHub 토큰을 학생 브라우저에 넣거나 저장소 파일을 직접 쓰게 하는 방식은 보안상 사용하지 않습니다.

## 개인정보 처리

브라우저 저장소 내부에서도 다음 값은 원문 그대로 저장하지 않습니다.

- 교사 내선번호: SHA-256 해시 저장
- 학생 생년월일: SHA-256 해시 저장

다만 이 버전은 서버 인증이 아니라 로컬 브라우저 인증이므로 실제 개인정보를 사용하는 공식 시험 운영용 보안 수준으로 보아서는 안 됩니다.

## GitHub Pages 배포

`.github/workflows/pages.yml`이 `main` 브랜치 변경 시 정적 사이트를 GitHub Pages로 배포합니다.

GitHub 저장소에서 한 번만 다음 설정이 필요할 수 있습니다.

1. `Settings`
2. `Pages`
3. `Build and deployment`
4. `Source`를 `GitHub Actions`로 선택

배포가 성공하면 일반적인 프로젝트 Pages 주소는 다음 형식입니다.

`https://ryujee79.github.io/yg_no_ai/`

## 개발 구조

- `index.html` : 진입 화면 및 외부 문서 처리 라이브러리
- `styles.css` : 전체 화면 스타일
- `app.js` : 교사/학생 시험 UI와 문제지 분석, 다운로드 기능
- `github-local-api.js` : 기존 `/api/*` 호출을 가로채 IndexedDB에서 처리하는 GitHub Pages 전용 데이터 계층
- `.github/workflows/ci.yml` : JavaScript 문법 및 필수 파일 검사
- `.github/workflows/pages.yml` : GitHub Pages 자동 배포

## Alt+Tab 관련 제한

일반 웹브라우저는 운영체제의 `Alt+Tab` 자체를 막을 수 없습니다. 현재 앱은 다른 창·탭으로 이동한 사실을 감지하여 기록하고, 전체화면 필수 시험에서는 전체화면이 풀리면 답안 입력 화면을 잠급니다. OS 수준 차단이 필요하면 Safe Exam Browser나 Windows 키오스크 모드 같은 별도 실행 환경이 필요합니다.
